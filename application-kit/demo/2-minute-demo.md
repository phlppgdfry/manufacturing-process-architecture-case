# Demo van 2 minuten

> Volgt de rondleiding op de live site: [demo/?tour](https://phlppgdfry.github.io/manufacturing-process-architecture-case/demo/?tour). Per stap wat je zegt. Een recruiter kan dezelfde demo alleen bekijken.
> *Independent portfolio case — fictional organisation.*

| Stap | Scherm | Wat ik zeg (±10 s) |
|---:|---|---|
| 1 | Catalogus, kerncijfers | "41 processen onder 10 end-to-end processen, uit één bron. Geen budget voor een tool, dus catalogus en modellen als bestanden met automatische checks." |
| 2 | Filter "zonder eigenaar" | "Acht processen zonder eigenaar. Dat is geen falen, dat is de werklijst." |
| 3 | Detail OTC-03 | "Leverdatum bevestigen: geen eigenaar, en de capability leverbelofte wordt door geen systeem ondersteund. Hier zit het conflict." |
| 4 | Review: automatisch rapport | "De draft van een analist: negen bevindingen op zeven regels, gevonden door het script." |
| 5 | Feedback | "Ik geef er vijf terug, over betekenis, elk als vraag. De vorm lost de analist zelf op." |
| 6 | Herwerkte versie | "Nul bevindingen. De inclusieve gateway werd drie duidelijke vragen." |
| 7 | Procesraad D-03 | "Wat geen model kan oplossen, beslist de procesraad. Gedeeld eigenaarschap weigert de catalogus." |
| 8 | Eventlog na beslissing | "Achter de schermen: model bijgewerkt, check groen, OTC-03 vrijgegeven." |
| 9 | Verbeteringen | "En het verbeterinitiatief op de leverdatum heeft nu een eigenaar en kan starten." |
| 10 | Beperkingen | "Wat gesimuleerd is en wat niet: de beslissing en release zijn gesimuleerd, de data en het rapport zijn echt." |
